# 七只入住小镇

大肥鱼、Claude、GPT / Codex、Gemini、GLM、Grok、Qwen 是七位常住居民。她们共用一栋小屋，沿花园小路走到湖边、茶桌、工作台、花丛、点心摊和广场路口，停下来做自己的事，偶尔两人交谈，也能沿镇上道路拜访现有项目屋。

## 入口和操作

- 世界地图工具栏「居民 7」打开居民面板并把镜头移到她们家；也可以点小屋或点居民。
- 查看居民期间暂停桌面巡游与新动态自动转镜；工作提醒继续入队，关闭居民面板后恢复巡游。
- 打开工作详情或侧栏只暂停镜头巡游，居民仍会散步、串门和回家；要暂停居民请用居民面板的「暂停散步」。
- 在名单中选一位，点「摸摸头」「去散步」「回家休息」。回家后会留在小屋休息，直到再次叫她出门。
- 拖动居民后会落在最近的花园小路上，避开小屋和水面。地图拖动、缩放与原来的项目入口继续使用。
- 「叫大家来喝茶」让七只沿路线在茶桌附近集合；正常碰面才增加友谊，不因点击集合直接加分。
- 选一位居民，在「去其他项目串门」中选屋子，再点「去串门」。她沿道路走到门口，进屋参观约半分钟，然后沿路回家。路上可点「看看她在哪」，进屋后可点「进屋看看」，屋门口也会显示来访头像。
- 来访居民在房间前侧过道走动，工作小人、工作台、项目结构和原来的操作照常使用；屋内工具栏也能打开「居民 7」。七只可以分别去不同屋子。
- 「自己去串门」默认开启，间隔轮流拜访附近项目；关闭后仍可手动叫她们串门。「回家休息」可中途召回；喝茶集合也会先叫访客回家。居民不会在多个地方同时出现。
- 「安静一点」收起气泡并停止自动对话；「暂停散步」保持位置；「显示居民」可以暂时隐藏立绘。
- 窄窗口保持原来的项目分页，点「居民 7」进入花园，「回到项目」恢复分页。`?view=town&world=1&residents=1` 可直接进入花园，配合 `kiosk=1` 使用桌面模式。

## 记录和边界

住处随现有地图布局保存在 `ss.town.layout.v1` 的独立住宅格子中；选用空格子，不挪动已有项目，新项目也不会占用这块地。生活记录在 `ss.town.residents.v1`，包括七只的位置、回家意图、串门目的地和往返路线、摸头次数、碰面友谊、最近十六条生活小事以及显示偏好。兼容首版记录；刷新后继续串门，项目从当前地图移除时会回家。记录仅在当前浏览器来源中保存，不写入项目工作数据库，也不在设备之间同步。

生活动作、寻路和台词全在本机运行，不调用模型、不安装 Agent 钩子、不读取对话和凭据。跨项目串门使用当前地图已有的项目名称、位置和入口，属于视觉生活动作；不会进入文件目录执行任务，也不增加项目、会话、运行、审批或交付计数，不替用户验收任务。工作历史回放不显示当前居民生活。后台页面和电脑睡眠不会补跑离线路线或积累一夜友谊。

生活时钟只刷新独立的居民组件，正常每秒两拍；暂停、隐藏、离开页面和离开世界场景都有对应处理。减少动态效果时取消人物摆动和镜头飞行动画。

## 本机验收动作

1. 打开合成演示的世界地图，点「居民 7」；名单和地图上共有七位。
2. 观察一段散步和一次两人交谈；「刚刚的小事」有对应记录。
3. 点大肥鱼，摸头，看到表情和文字反馈；送她回家，等待走到小屋并休息。
4. 刷新，再打开居民面板；回家状态、摸头次数和已积累的友谊仍在。
5. 叫她散步，再拖一位居民到附近；落脚点在小路上。
6. 叫一位去示例项目串门，看到沿路行走、门口来访头像和「进屋看看」；进入房间看到来访居民，再回世界或叫她回家。工作项、审批和验收数字不受居民操作影响。
7. 在窄窗口进入花园并操作一位居民，再返回项目分页。

自动检查：`web/` 中运行 `npm test` 和 `npm run build`；新增测试覆盖花园和项目道路寻路、进屋及返回、七只独立目的地、中途反复召回、损坏记录、刷新恢复、离线时间跳跃、目的地消失、自动串门开关、对话冷却、暂停、存储禁用、住宅格子稳定及素材完整性。
