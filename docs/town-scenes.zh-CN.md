# 小镇场景切换与微缩庭园

用户于 2026-11-05 确认 A「微缩模型庭园」为柔和手绘之外的第二套画风，并授权开发首页的场景切换菜单。

## 定稿方向

- 微缩庭园使用圆润的木制与陶土模型感，清透绿地、奶白墙面、珊瑚色屋顶与柔和落地投影。
- 七只原 CrossPet 角色不重绘。柔和手绘与微缩庭园共用 Claude／Codex 工作会话立绘、编号、provider 和状态。
- 沿用 React/SVG 等距世界、独立对象、点击入口、居民道路与镜头跟随；环境不合成单张平面背景。
- 色彩与模型尺度的公开参考为 [Townscaper 官方图集](https://www.townscapergame.com/)。本项目素材独立生成，不使用该游戏资产。

## 首页操作

进入小镇后，顶部“场景”打开缩略卡菜单：微缩庭园、柔和手绘和兼容旧版的经典小镇。

1. 点缩略卡临时预览整镇外观。
2. 点“使用此场景”保存当前选择；会清除临时 `town-art` 参数，其他地址参数和片段保持。
3. 点取消、关闭、菜单外或按 Esc，回到打开菜单时的场景。室内取消预览不会触发“回到世界”。
4. 素材准备完成后切换。加载失败保留原画面；连续选择和取消不会被迟到的加载结果覆盖。

菜单打开时暂停自动巡游／分页，显式居民跟随保持。桌面三列卡片；窄屏为纵向卡片并限制在窗口内。键盘可用方向键、Home、End 和 Esc。

## 存储与兼容

独立键 `ss.town.appearance.v1` 只保存 `{ "version": 1, "theme": "miniature" }`，不写居民生活、项目布局或工作数据。有效主题为 `original`、`storybook`、`miniature`。

- 初次显示优先级：有效 `town-art` 临时参数、已保存选择、经典小镇。
- 旧 `town-art=storybook` 链接继续有效，不会自动覆盖本机选择。
- 旧用户、未知主题、损坏偏好或未知版本回到经典小镇。存储不可用时仍可在本次打开中使用，并显示说明。
- 偏好属于当前浏览器／App 数据存储与来源地址；不同浏览器、端口、设备不自动同步。不新增多人账户。
- 本轮不增加角色独立小院或项目逐间装修。后续若扩展房间主题，需使用稳定项目身份，不能使用项目显示名或合并后的偏移编号作为持久键。

## 已实现范围与交付边界

微缩主题包含居民住宅、矮层项目屋、两种模型树、圆润针叶树、花丛、石头、道路、池塘与湖面，以及室内家具、墙面与地面配色。工坊与高楼沿用现有几何结构，适配模型配色与屋顶，尚未制作各自专用的模型图集。

首个可玩场景以三个合成项目和七位居民验证。真实 App 替换、主线合并、远端推送和用户验收均不由本地构建或 Agent 自测代替。
