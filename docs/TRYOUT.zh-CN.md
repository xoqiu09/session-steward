# Session Steward 试用说明（v0.2.0）

谢谢你来试用。这份说明带你用大约 30 分钟走一遍主要功能。我们最想知道的是：**哪一步卡住了、哪里看不懂、哪里和你预期的不一样。** 不用评价代码，也不用替我们找原因，照实记下你看到的就好。

## 开始前

- 一台 Mac（macOS 13 或更新，Apple 芯片或 Intel 都行）。
- 平时在用 Claude Code 或 Codex（任一即可，桌面版或命令行版都行），最好手上有一个可以让它改点东西的项目。最好是 Git 仓库，没有也能试大部分功能。
- 准备一个记录的地方，每个任务后面都有“记下来”。

Session Steward 只在你的电脑上运行，数据存在 `~/.steward`，不上传任何东西。它会在 Claude Code 和 Codex 的配置里加几条 hooks，改之前会备份，卸载时会恢复原样。

## 任务 1：装好并打开（约 5 分钟）

1. 按 [README 的“三步装好”](../README.md#三步装好) 下载、放行、打开 App。
2. 按引导点“安装 hooks 并开始”。用 Codex 的话，在 Codex 里信任新加的 hooks。
3. 看一眼小镇：刚装好时是空的。

记下来：
- 从下载到看到小镇，哪一步犹豫过或做错过？macOS 拦截那一步顺利吗？
- 引导里说要改的文件、要做的事，你看懂了吗？

## 任务 2：让 Agent 干一件小事（约 10 分钟）

1. 新开一个 Claude Code 或 Codex 会话，给它一个 5 到 10 分钟能做完的小任务，例如“给 README 加一节安装说明”。
2. 回到小镇，看会不会出现一栋房子和一个小人。
3. Agent 要执行命令时，看看告示栏和面板右侧队列里有没有出现请求；试着在面板里点一次“允许”或“拒绝”。
4. Agent 做完后，看菜地里的菜有没有“熟了”，点“收菜”看它交付了什么，然后点“已处理”或“退回”。

记下来：
- 房子、小人、熟了的菜，分别是什么意思，你是看图猜出来的，还是看了说明才知道？
- 在面板里处理权限请求，比在原来的会话里处理方便还是麻烦？
- 收菜时看到的内容，够不够你判断这件事有没有做好？

## 任务 3：在小镇里找东西（约 5 分钟）

1. 点一个项目的名牌：镜头应该飞到那栋房子和门前的菜地，你还在世界地图里。
2. 点“回到刚才的位置”。
3. 点房子本身，走进项目内部看看，再按 Esc 出来。
4. 刷新一下页面（或者退出 App 再打开），看看房子是不是还在原处。

记下来：
- 名牌和房子点起来的区别，你觉得自然吗？
- 有没有哪次镜头自己飞走了，打断了你正在看的东西？

## 任务 4：同时开两个会话（约 5 分钟）

1. 再开一个会话，可以是另一个项目，也可以是同一个项目，让两个 Agent 同时干活。
2. 在小镇和完整面板（菜单栏小房子图标 → 打开完整面板）里，看看能不能分清谁在干什么、哪个在等你。

记下来：
- 你能不能一眼说出“现在有几件事在等我”？
- 项目简报里的“结论、卡点、下一步”对你有没有用？

## 任务 5：卸载（约 2 分钟，可选）

如果你不打算继续用：App 菜单选“卸载 hooks…”，再“退出并停止采集”，把 App 拖进废纸篓。

记下来：
- 卸载后，Claude Code 和 Codex 用起来是不是和装之前一样？

## 最后，三个问题

1. 如果明天还能用，你会继续开着它吗？为什么？
2. 哪一个地方最让你困惑？
3. 你最希望它多做一件什么事？

## 怎么反馈

把记录发给邀请你的人，或者发到 [Issues](https://github.com/xoqiu09/session-steward/issues)。截图很有帮助，但请先确认里面没有不想公开的项目名或内容。**不要贴登录链接、token、`~/.steward` 下的文件或对话全文。**

附上版本会方便我们复现：App 菜单“关于 Session Steward”里能看到；也写上你用的是 Claude Code 还是 Codex，以及它们的版本。
