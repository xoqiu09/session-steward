状态：D0 冻结后可用合成输入；真实来源展示等待 P1/A0。**用户新增的花园/片区手动导航也仅为待实现计划，本轮未写代码、未点验或生成验收截图。**

共用约束：[索引与回报格式](README.zh-CN.md)；[契约提案](../architecture-addendum.zh-CN.md)。

## 目标

项目状态变化时房子不乱搬；用户点击项目名即可在世界里看清房子、门前花园和对应工作，并能返回刚才的视角与显示范围。任务详情继续复用现有首屏，与地图定位分别进入。

- 复用 world.ts/clusters.ts/route.ts/WorldScene；初始世界沿用现有分组，后续稳定项目键增量分配坐标，状态/活动排名只改表现。
- 保存每个设备视图范围的相机；切本机/全部设备、刷新和重连保持已有地块与返回视角；不要把 hub 偏移数字当持久身份。
- 复用 [WorldScene.tsx 中的 WorldStage](../../../../../web/src/town/WorldScene.tsx) 现有 flyTo、fitCamera/cellBox、returnCamera、lastTouch/followUntil、减少动效与 swallowClick 拖动抑制；为下表入口提供同一项目/片区导航意图，不另建地图、相机或动画系统。I0 负责公共入口最终接线与组件验收。
- 当前 WorldScene 的远景项目牌通过 activate→building Selection，再由 sceneSelect/setInside 进入室内；片区 FarPlate 尚无独立片区取景。未来 W1 须把“项目名牌/片区导航意图”与“建筑进入 Selection”分离，不让新导航再走这条室内分支，并同步 [TownGuide.tsx](../../../../../web/src/town/TownGuide.tsx) 现有“点房子或名牌走进内部”说明；本轮不改这些源码。

- 将常驻项目与活跃状态分离；归档/回收站继续通过 ProjectsPanel，恢复优先回原位，归档不因常驻自动复活。
- 复用 WorkOverview/RunDesk/原会话入口，补依据与时间、能力缺口；技术记录保持折叠，普通工作继续叫已处理。
- 沿用仓库已有 [town.css](../../../../../web/src/town/town.css)、[townView.css](../../../../../web/src/town/townView.css)、[WorkOverview](../../../../../web/src/ui/WorkOverview.tsx) 与 [RunDesk](../../../../../web/src/ui/RunDesk.tsx) 的组件、字体、颜色与间距；这些是跨机器可读取的源码依据，不依赖仓库外技能路径。先测试 36 本机/48 全部设备合成世界，不生成假项目填充正式数据。

## 手动导航交互契约（待实现）

| 用户入口 | 应有行为 | 命中与事件边界 |
| --- | --- | --- |
| 项目名牌 | 立即发起既有镜头定位，放大到房子、门前花园和该项目对应工作可辨认的范围，仍留在世界。 | 以来源设备＋稳定项目 ID 命中；不借房子 click 进入室内，不顺带打开任务处理。 |
| 片区标题，如“LocalDevData 一带 · 7 个项目” | 用该片区全部项目的布局边界取景，并通过合适的 LOD/局部显示让七个成员项目的名牌实际可见且可点击；随后可选其中某项目去花园。 | 标题绑定片区身份/成员集合，不把显示文字当项目 ID，不取第一个项目代替片区导航，也不能只 fit 边界却仍把成员聚合隐藏。空片区显示原因。 |
| 房子本体、明确“进入工作室”入口 | 才进入该项目室内/工作室。 | 名牌、片区标题、工作徽章有独立语义；点击一次不能同时触发导航和进入室内。 |
| 状态/工作徽章 | 保留原有查看或处理动作。 | 阻止事件冒泡触发房子/名牌动作；不因增加地图导航改掉现有徽章功能。 |
| 项目列表中的项目名、“去花园” | 复用与项目名牌相同的导航入口和身份解析。 | “任务详情”保留独立入口，不用去花园替代详情，也不把点项目名变成开任务详情。 |
| “回到刚才的位置” | 恢复手动导航前保存的完整相机与显示范围。 | 包含中心/平移、缩放、设备/视图范围、筛选与当前显示边界；不能只回房子坐标或只重置全景。 |

- **手动立即响应，自动仍保留三秒。** 名牌、片区、列表和返回操作直接派发既有镜头动作，不进 moments 的三秒归并窗口；“立即”指不等待自动事件聚合，实际飞行沿用现有动效。减少动画时直接定位。原 V1 自动事件仍按三秒窗口、优先级和保护条件处理。
- **返回点完整且不被覆盖。** 首次手动导航前保存上述相机＋显示范围；连续导航沿用该返回点，不能用飞后的新落点覆盖；点击返回后清理。用户拖动/缩放后的返回点清理沿用既有 WorldStage 规则并给明确反馈。若原范围已不可恢复，解释变化原因，不能悄悄回到另一设备/同名项目。
- **防止立即被抢镜。** 手动导航、片区选择和返回均记录用户操作，复用 lastTouch 与至少30秒操作保护；自动巡游/自动跟随不能刚定位或刚返回就抢走镜头。显式手动入口不被三秒聚合拖延，自动保护不因此取消。
- **身份与缺失。** 复用 D0，项目导航身份是来源 host/device_id＋来源原始项目 ID（稳定项目身份），经统一解析器映射到当前布局的 building key；不把合并后的偏移 repo_id、显示 name、项目排序或当前 building key 当永久来源身份。两设备同名仍定位各自房子；缺原始身份时保留兼容/信息缺口，不猜同名目标。远端项目只读，点击不发业务写入。已归档、不存在、来源设备不可用或布局尚无目标时说明原因，不自动恢复、不跳替代项目；显式筛选外的定位如需临时调整显示范围，必须记录并可完整返回。
- **输入可达且单动作。** 入口使用有可理解名称的按钮/链接，键盘 Enter/Space 能触发相同意图；焦点与返回入口可见。拖动/缩放手势结束不能误触名牌/房子，徽章与嵌套入口用独立命中/冒泡保护，减少动效设置沿用既有实现。
- **纯导航。** 名牌、片区、列表定位和返回只改界面导航状态/本地视角偏好，不创建交付、不标已处理、不批准、不写功能符合要求；不触发收菜等业务动作。W1/I0 用合成请求记录证明导航链业务写入为0，不能把这一目标写成当前已验证。

## 验收标准

1. 状态切换、加项目、设备排序变化不重排已有建筑；常驻与归档冲突有明确规则。
2. 宽屏完整世界和工作室入口分开，单设备仍可用世界；窄屏沿用现有分页，另行设计前不承诺窄屏世界。显式筛选不偷偷恢复全部项目。
3. 定位后返回相同范围和镜头；目标归档/不存在时显示原因，不跳到同名别项。
4. 首屏含发生什么、依据时间、下一步和去处理；键盘、窄屏、减少动画可用。
5. S27 的项目名牌/列表“去花园”按来源设备＋项目身份立即定位到房子和花园、对应工作可辨认；片区标题取景全部七项目并能继续选项目，不能取第一个；仅房子本体/明确工作室入口进室内，状态徽章保持原功能且一次点击只有一个动作。
6. 手动导航不等三秒，返回完整恢复导航前相机和显示范围；连续导航不覆盖返回点，导航/返回后30秒自动巡游不抢镜。键盘、减少动效与拖动不误触均有组件证据，远端只读、归档/缺失解释且不恢复/替代，导航业务写入0。

## 验证

未来实现后做前端测试/构建，36本机/48全部设备（30+项目）实际合成预览，包含两设备同名项目与七项目片区；按 S27 记录名牌/片区/列表/徽章/房子/返回/拖缩/键盘/减少动效及导航业务写入0。I0 实际组件点验至少保留同一候选的“点击前、花园定位后、返回后”三张截图，返回后逐项比较相机与显示范围；旧 V1、项目管理和深链回归。本轮仅校验文档，没有执行上述测试或截图。每条标准写满足/不满足/无法验证；模拟 expected 不得填成真实已通过。
