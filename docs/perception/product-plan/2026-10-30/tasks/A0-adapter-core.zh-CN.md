# A0：公共身份、能力与 MCP/CLI 回报层

状态：D0 冻结、P1 整合后；可先做隔离协议验证。
分支建议：`feat/adapter-core`。执行时从最新 main 创建独立 worktree；当前没有创建该分支。
共用约束：[索引与回报格式](README.zh-CN.md)；[契约提案](../architecture-addendum.zh-CN.md)。

## 目标

让不同工具进入同一状态机，能力缺口透明，公共桥接只有一个维护者。

## 范围与复用

- 保留 provider 旧值与现有会话主键，execution_tool 仅是文档语义，不新增列。新工具 provider 使用明确的 workbuddy/deepseek_harness 等 ID，在 ResolveSession 原生 ID/目录候选两处都精确匹配，不借空值/other 跨工具猜测；缺失原生 ID 时使用显式桥接身份。模型厂商/名称的新增采集和记录必须先获用户 U03 授权，否则不启用、不猜测。
- 实现能力声明与版本化证据、连接健康、受控处理入口；旧客户端缺字段保持 unknown，不误称所有能力已连接。
- 提供最小 begin/report/deliver 及必要事实读取桥接，复用原简报和交付逻辑；标为 Agent 主动回报，不制造自动监听。
- 本机 stdio/CLI 优先；独立授权限定工具、项目、会话和动作，不能复用 hub 密钥或全权限面板 token。
- 事件、schema、快照、公共路由和依赖仅由该负责人提出并按公共所有权串行接入；新增迁移走 U1 兼容流程。
- 若日后获分配统一本机控制实现，按D0把生命周期/幂等/输入所有权/审计统一到managed_sessions等机制，收敛外部PR #42，不另建状态机。只控制Mac Studio本身；独立可撤销逐动作凭据不复用观察MCP/remote.token/面板/hub密钥。当前用户已授权PR #42按手机暂只拒绝、批准回本机收紧（远端allow403并隐藏、本机明确允许保留），最终产品默认/凭据细节仍待确认；普通remoteBlocked及其他设备只读不变，真实手机网络待决定，本包不实现或验证该原型修订。
- 第一阶段复用SS原对象/人物和V1离开期间提示，明确原生ID的CLI resume与桌面codex://threads接手分别验；明确交付到review/菜熟，绝不自动已处理。模型设置归Codex，界面沿用小镇，不接入Ekko整套或配置/会话库。

## 不做

观察桥接不提供控制、权限批准、发送消息或读对话；独立本机控制按D0及用户已给保守默认/后续确认，不由观察接入启用。不得放宽remoteBlocked或复制任务/控制数据库，不据此开放手机允许或真实网络。Ekko只参考思路按SS自实现个人使用，禁止整套接入、复制/AI改写代码或依赖，不引入Vue/Koa/profile/model-provider/workspace/session-library或改Codex模型设置。

## 验收标准

1. 两工具/两设备同原生 ID 不串任务，两处 other 分支的明确工具 ID 与旧兼容分别覆盖；换模型不新建会话，未授权不新增模型记录；旧记录/摘要仍可读。
2. 重复回报幂等；越权项目、伪装工具/设备、伪造事实来源和已处理/批准/安装写入被拒绝。
3. 离线/未知/不支持/未验证和验证证据分别显示，不由连接成功一键变绿。
4. 停用/卸载撤销自身授权和配置，保留业务历史，不改变现有 Claude/Codex 设置。

## 验证

协议模拟、权限/幂等/兼容及竞态检查；使用合成 home 和假工具，不接真实账号。 每条标准写满足/不满足/无法验证；模拟 expected 不得填成真实已通过。

## 交付

公共桥接草稿 PR、契约版本、最小客户端样例和自身配置移除说明。 按共同六段格式回报，附精确候选、证据和未验证项；没有 PR 则明确仅设计/调研。用户确认与执行者自测分开。
