# W2：复用 V1 的动态恢复与来源映射

状态：D0 后可独立逻辑开发；P1/P2 等新来源按依赖接线。
分支建议：`feat/town-moment-recovery`。执行时从最新 main 创建独立 worktree；当前没有创建该分支。
共用约束：[索引与回报格式](README.zh-CN.md)；[契约提案](../architecture-addendum.zh-CN.md)。

## 目标

刷新、断线和重启不会把旧交付当新交付，重要事件仍能定位且不抢镜头。

## 范围与复用

- 基于 moments.ts/useMoments.ts 增量开发，保留 3 秒归并与优先级、30 秒静默、详情/室内/收菜/回放/后台保护。
- 按冻结契约保存看过标记、范围和快照代际；旧 LAST_SEEN 数据尽力兼容，不能只依赖易漂移的浏览器时间判定全部新旧。
- 同一交付修订或快照重发不重飞；断线追回只出现离开摘要；存储不可用时明确降级但本次会话仍去重。
- 新增已核实 PR 变化和各适配器观察的映射，Agent 自述与程序核实不同；无信号只显示信息缺口，归档/自动记忆整理不进待办。
- 先交独立逻辑和 hook 接口；WorldScene/App/公共路由接线由 W1/I0 单一负责人处理。

## 不做

不另建第二套动态队列、系统通知或后台模型轮询；不擅改三秒选择。

## 验收标准

1. 同时事件只在完整三秒窗口后选最高优先级，其余入原队列。
2. 刷新、SSE 重连、页面重开和设备短离线后不会重播相同交付。
3. 用户拖动、阅读和处理期间不抢相机；手动定位与返回位置正确。
4. 无模型解释时动画仍工作；远端事件保持只读，不自动批准或已处理。

## 验证

模拟时钟、持久存储及重连测试；前端测试/构建；I0 实际截图和键盘/减少动画检查。 每条标准写满足/不满足/无法验证；模拟 expected 不得填成真实已通过。

## 交付

恢复/去重语义说明、模拟记录及草稿 PR，列出等待公共接线的地方。 按共同六段格式回报，附精确候选、证据和未验证项；没有 PR 则明确仅设计/调研。用户确认与执行者自测分开。
