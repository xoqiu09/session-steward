# P6：SS 事实与独立模型解释接口（预备草案）

状态：P1、D0 后更新；接口冻结后允许 P6b 用模拟服务并行。
分支建议：`feat/perception-interpretations`。执行时从最新 main 创建独立 worktree；当前没有创建该分支。
共用约束：[索引与回报格式](README.zh-CN.md)；[契约提案](../architecture-addendum.zh-CN.md)。

## 目标

让小猫只依据可回查事实解释项目，不直接改变业务状态。

## 范围与复用

- 基于快照提供项目级/合并视图事实和信息缺口；最小字段白名单、认证和数据版本由 D0/A0 统一。
- 独立写入解释：种类、文本、模型、生成时间、依据 ID/时刻和版本；不走事实 Ingest，不能伪造 verifier。
- 面板复用现有 WorkOverview 加独立小猫看法；知道了/不对只记录反馈。
- 远端仅用允许摘要引用，禁止把本机 Ref、路径、命令或对话通过点击证据接口泄漏。
- 现有 ai_summaries 保持兼容；按依据版本缓存、过期和节流，不对每个动画帧或每次轮询调模型。

## 不做

无对话正文、无自动远端模型兜底；不直接改小猫仓库。

## 验收标准

1. 解释尝试写已处理/审批/合并/安装/运行事实被拒绝。
2. 依据不存在、跨项目/跨授权范围、旧版本和远端不可查时有明确状态。
3. 模拟事实变化使旧解释过期；模型不可用时基础状态仍正确。

## 验证

权限、来源和反馈测试，假模型客户端；组件预览与合成截图，完整回归。 每条标准写满足/不满足/无法验证；模拟 expected 不得填成真实已通过。

## 交付

冻结的事实/解释契约、SS 草稿 PR 与 P6b 模拟服务样例。 按共同六段格式回报，附精确候选、证据和未验证项；没有 PR 则明确仅设计/调研。用户确认与执行者自测分开。
