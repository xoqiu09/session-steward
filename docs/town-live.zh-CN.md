# 小镇直播展示

在本机 SS 的“小镇 → 放映角”打开展示工作台（“工具 → 直播”也可进入）。这里可以保存公开主题、最近思考和交流方式，选择温暖夜景、清新绘本或 AI 工作室，并切换横竖屏预览。

“小镇 + 放映角”让小镇实况、七位居民与公开内容同屏：默认小镇为主，也可选择内容为主。展示最多八个最近项目与居民小屋，七位居民沿共用道路散步；这是视觉生活，不会启动 Agent 生产任务。换卡片不重建小镇或重置散步。“居民 + 小镇”保留原来的小院陪伴布局；“整座小镇”保留全幅小镇展示。预览和 OBS 使用同一页面，横屏按 1920 × 1080、竖屏按 1080 × 1920 渲染，竖屏底部约四分之一留给平台评论。

公开轮播从空清单开始，不自动读取罗盘、笔记、书房或任何项目文件。主人可以添加最多 24 张卡片，填写来源、标题（48 字）、正文（240 字）和出处（80 字），同时勾选“加入播放”和“我已检查内容，可以公开”，保存后才进入展示。修改文字或来源会撤回该卡的公开确认；关闭未保存的清单会先提示。横屏把“旷野之心”统一替换成中性名称“想法便笺”，包括标题、正文、出处、说明和无障碍名称；竖屏可以保留原名。

可选每张 20、40、60 秒，另有开始、暂停和下一张；暂停保留当前卡片，小镇继续运行。App 和 OBS 按同一服务端起点换页。编辑清单不会自动开始播放。两个控制窗口同时修改时，后保存者会收到冲突提示；未确认写入结果时保留草稿，先重新读取再决定下一步，不自动重试。

草稿保存在独立的 `meta` 键。`GET/PUT /api/live/content` 只允许本机面板；展示凭据无法读取草稿或控制播放。公开清单以白名单重建后包含在 `/api/live/note` 中，因此展示页仍只轮询 `/api/live/snapshot` 和 `/api/live/note`，不写浏览器存储。无卡片时显示安静的放映角说明，不编造作品、进度或实际制作任务。

阅读来源的公开卡片顶部在横竖屏中均使用“随读片段”，不附加书名或来源名称。实际选片与出处仍可留在本机工作台和选片记录中；摘意应注明“非逐字原文”，不冒充原句。

说明文字是用户主动公开的内容，不会自动从工作项或会话提取。小镇只显示通用项目名、Agent 名和工作数量；动态来自相邻快照的状态变化，套用固定句式，首次打开不会编造进度。

在工作台里点“摸摸”“去散步”“该回家啦”，约两秒后预览和 OBS 中的居民会回应。动作只改变展示，不会给 Agent 发指令，也不会修改工作项。此版本尚未接入抖音或其他平台的弹幕，留言卡只是直播间交流提示。

把“复制展示地址”取得的地址填入 OBS 浏览器源，竖屏尺寸设为 1080 × 1920。地址包含独立展示令牌，请只放进采集软件。展示凭据只能读取脱敏快照与公开说明，不能操作工作台或其他面板接口。展示仍然只支持本机访问。

切换布局、画风或修改说明后需要保存；工作台中的布局和画风可以先试看。关闭未保存的草稿会先提示确认。配置预览和虚拟摄像机不会自动开始平台直播。

七位居民（ChatGPT、Claude、大肥鱼、Gemini、GLM、Grok、Qwen）共用同一套直播出场设置，默认每 2 分钟轮换一位。可选 1、2、5 分钟，也可固定一位；点击头像会立即点名，并从该角色重新开始一轮。App 与 OBS 使用同一时钟和保存的起始时间，动作播完才自动换人。切换角色时，立绘、名字、留言卡与固定回应一起更新。出场设置立即生效，与公开主题草稿分开保存。
