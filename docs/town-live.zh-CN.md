# 小镇直播展示

在本机 SS 的“小镇 → 工具 → 直播”打开展示工作台。这里可以保存公开主题、最近思考和交流方式，选择温暖夜景、清新绘本或 AI 工作室，并预览观众画面。

“团子 + 小镇”把陪伴角色放在小院中，右上角保留“小镇刚刚发生”和“给团子留句话”，下方展示现有小镇的脱敏实况；底部留给平台评论。“整座小镇”保留原来的全幅小镇展示。预览按 1080 × 1920 渲染，与 OBS 竖屏浏览器源使用同一页面；横屏会自动调整布局。

说明文字是用户主动公开的内容，不会自动从工作项或会话提取。小镇只显示通用项目名、Agent 名和工作数量；动态来自相邻快照的状态变化，套用固定句式，首次打开不会编造进度。

在工作台里点“摸摸团子”“去散步”“该回家啦”，约两秒后预览和 OBS 中的居民会回应。动作只改变展示，不会给 Agent 发指令，也不会修改工作项。此版本尚未接入抖音或其他平台的弹幕，留言卡只是直播间交流提示。

把“复制展示地址”取得的地址填入 OBS 浏览器源，竖屏尺寸设为 1080 × 1920。地址包含独立展示令牌，请只放进采集软件。展示凭据只能读取脱敏快照与公开说明，不能操作工作台或其他面板接口。展示仍然只支持本机访问。

切换布局、画风或修改说明后需要保存；工作台中的布局和画风可以先试看。关闭未保存的草稿会先提示确认。配置预览和虚拟摄像机不会自动开始平台直播。
