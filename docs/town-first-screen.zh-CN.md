# 小镇首屏规格（草稿，待你确认）

> 用途：先定"打开小镇想看到什么"，之后只做直接服务这页的改动。验收标准由你来判，Agent 只报实现和测试结果。

## 1. 使用场景

- 小镇挂在副屏上常开，大部分时间不碰鼠标。
- 顶部的动态卡（"小镇灵动岛"）在事情发生时提醒你，类似 Agent notch。
- 你会中途出门，回来后要能马上接上：哪些没收、哪些停着。
- 看完之后你通常会推进下一轮任务。

## 2. 小镇要回答的四个问题（按优先级）

| # | 问题 | 现在有什么 | 缺什么 |
|---|---|---|---|
| Q1 | 有没有 Agent 做完了、我还没验收的？已经等了多久？ | 名牌上有"验收 N"；有新交付时灵动岛弹"菜熟了"；回来时有"你离开期间：N 棵菜熟了" | 离开提示只算**离开期间新熟的**。离开前就熟了、一直没收的，看过一次后就不再提醒，这正是"忘了验收"的情况。也看不到等了多久 |
| Q2 | 有没有停下来、没人推的工作？ | 小人有"空闲（未完成）"和"状态待更新"；工作项有"受阻" | 没有"停在你手上"这个概念：Agent 停了、工作没做完、下一步该你推的事，灵动岛和名牌上都不提醒 |
| Q3 | 每个项目推进到哪了？几个 Agent 在做？ | 名牌上有决定、工作、验收、受阻四个数；可以按 Claude / Codex 查看会话数 | 核心功能数据已经有（Agent 回报的已完成 / 开发中 / 未开始），但只在"项目简报"和详情里用，**小镇完全没用**；房子也没有悬停信息 |
| Q4 | Agent 建议我下一步做什么？ | 工作项简报里有"下一步"和"该谁做"，要点进去才能看到 | 首屏和房子上都看不到 |

## 3. 先做的改动（只服务上面四个问题）

**A. 待验收的提醒不随时间消失（Q1）**
灵动岛上方常驻一行："还有 N 件等你验收，最久的已经等了 X 小时"，点一下开始收菜。离开提示也算上离开前就熟了、还没收的。熟了超过 30 分钟还没收，灵动岛再提醒一次。
- 验收标准：副屏上不碰鼠标，10 秒内能读出待验收几件、最久等了多久；刷新页面或隔天打开都还在，直到真正收下或退回。

> 名词关系："待处理"（顶部"要你处理 N 件"）= 要你决定 + 菜熟了（待验收）+ 卡住了。"菜熟了"是其中一类：Agent 已交付，等你收下（标记"已处理"）或退回修改。

**B. "停在你手上"（Q2、Q4）**
工作项没完成、没有 Agent 在干活、超过 N 分钟没动静、最后的下一步写着该你做（或没写）时，判定为停着。灵动岛提醒一次，房子上出现标记，并显示 Agent 最后给的下一步建议。
- 验收标准：你停下手边的事 N 分钟后，小镇能指出是哪件、停在哪、Agent 建议你做什么。

**C. 房子信息卡（Q3、Q4）**
在房子上显示：几个 Agent 在做（Claude / Codex 各几个）、核心功能清单（已完成 / 开发中 / 未开始）、最近一条下一步建议。点进去仍是现在的项目内部。
- 验收标准：不点进项目，就能说出这个项目哪些功能已经做完、哪些在做。
- 前提：核心功能要 Agent 回报过才有。没回报的项目显示"还没登记核心功能"，不靠猜。

**D. 感知你在对话里已经接着推进了（Q1，已确认方向）**
菜熟了以后，你又在同一个 Claude Code / Codex 会话里发了消息（不论说的是"验收通过"还是直接布置下一步），Hook 会记下"交付后你回来过"，只记时间，不读也不存你说了什么。灵动岛随后提示："你已经在 Codex 里接着推进 X 了，这件算处理了吗？"，给出"已处理""退回修改""稍后"三个按钮。
- 不强制：不点也行，菜保持熟着，只是待验收提醒里标为"你回来过"。
- 只有你点"已处理"才收下；Agent 说的话不算数，也不会自动收下。
- 点完以后 3 秒内，菜从地里收走，灵动岛显示一次"已收下"。
- 验收标准：你在对话里接着推进后 1 分钟内，灵动岛出现这条提示；直接在灵动岛点完就处理掉，不用再进面板。

## 4. 减法（已确认）

- 隐藏：回放条、5 个高亮筛选、包裹 / 退件筐 / 小纸箱。在"小镇怎么看"里加开关，要用时再打开。
- 保留：桌面巡游、小地图。
- 顶部"画布"视图移到不显眼的位置（暂不删除）。
- 不删数据，只调整首屏上能看到什么。

## 5. 这次不做

远程访问和手机布局、重构、新的比喻元素。

## 6. 已确认的决定（2026-11-01）

1. 对话里的验收：不按关键词自动收下。交付后你回到会话发消息，灵动岛问一句、一键处理，不强制（见 D）。
2. "停着"按 30 分钟算；菜熟了 30 分钟没收也提醒（见 A、B）。
3. 房子信息卡：鼠标悬停显示简要信息，点进房子看完整的核心功能。
4. 减法见第 4 节。
5. 画布暂时不用，先移出主导航。

## 7. 实施顺序

1. 减法（纯前端，最快能看到"变清爽"）。
2. A：待验收提醒常驻和 30 分钟再提醒（纯前端）。
3. D：交付后回到会话的感知（后端记时间 + 灵动岛提示）。
4. B：停在你手上。
5. C：房子悬停卡和项目内部的核心功能。
