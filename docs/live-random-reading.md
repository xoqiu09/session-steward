# 直播随机摘句

直播设置可在“手动清单”和“随机摘句”之间切换。摘句库独立保存，切换不会覆盖手动卡片，日常小镇不参与。保存设置不会自动开始已暂停的轮播。

先在“摘句库”选择 JSON 文件，预览数量和第一句，再点“导入并确认可以公开”。只导入主人已筛选、允许公开的内容；程序不会扫描私人目录。库内最多 12000 句、文件最多 4 MB。来源暂限阅读摘句，每条需有独立短句和已有主题，正文留空。公共画面不显示书名、原帖编号、日期或原库数量。

合成格式示例：

```json
{"source_count":1,"items":[{"id":"synthetic-example","source":"kuangye","title":"合成问题：选择的边界，在哪里？","body":"","credit":"摘句","topic":"thinking"}]}
```

主题枚举沿用 13 间主题小屋：emotion、thinking、self、growth、relationships、wealth、investing、business、society、ai、meaning、health、family。归类来自导入文件；展示页不推断正文语义。

随机模式每轮打乱，一轮内每句一次，跨轮避免连续重复（只有一句时除外）。种子和播放位置保存在本机服务，多个展示窗口按同一时钟播放；刷新不会重新抽签。下一句、暂停、继续均有修订检查，过期控制不会覆盖新设置。替换摘句库会重置随机顺序，保留播放或暂停状态。

展示接口仍只有 `/api/live/note` 和 `/api/live/snapshot`；摘句池及播放控制仅本机面板身份可访问。每次展示只拿 24 个即将播放的片段，每 12 句更新窗口；短时断网仍能继续，窗口用尽后停在最后一句，恢复连接后跟上当前进度。不会把整库发给 OBS，也不写浏览器存储。

卡片、亮灯和带路居民共用展示时钟。小人仍沿原有路网行走，换主题只更新目标，不重建地图；同主题继续停留。现有手动卡片、七位居民轮换、普通小镇和真实工作记录保持各自的状态。

自动测试的长时钟推演只验证顺序与窗口，不代表真实 24 小时运行验证。是否开播始终由主人决定。
