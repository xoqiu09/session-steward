# Resident artwork

Selected, unmodified character artwork from [CrossPet v1.3.10](https://github.com/lokicorvus/crosspet/tree/v1.3.10/characters), by lokicorvus and CrossPet contributors. Source files are mapped in source.json; filenames in this copy describe their use in the town.

These assets are for the user's local, non-commercial town. The project's MIT code license does not relicense them.

DeepSeek and GLM derive from community character designs, including 上善无形 and ZipZipPipe; Grok and Qwen derive from ZipZipPipe designs. CrossPet supplies the desktop-pet artwork and its original character settings. See the linked credits and included license for each character's full provenance.
